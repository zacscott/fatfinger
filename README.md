# fatfinger

Your AI writes flawlessly, you don't.

fatfinger takes a clean AI draft and gives it the human touch.

## Install

```bash
uv tool install --editable git@github.com:zacscott/fatfinger.git
```

OR

```bash
uvx --from git@github.com:zacscott/fatfinger.git fatfinger
```

## Use

```bash
echo "Looks good to me. Approved!" | fatfinger sloppy
```

```
LOoks good to me. approved!
```

| Preset | Sounds like |
|---|---|
| `pro` | Talking to the CEO |
| `mid` | Talking to the team (default) |
| `sloppy` | Typing on your phone while walking to the car park |
